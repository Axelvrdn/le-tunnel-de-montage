# Le Tunnel de Montage

Application web pour centraliser les demandes de montage autour de vlogs YouTube.

Les membres d'un groupe peuvent signaler un moment précis d'une vidéo, choisir une fenêtre avant/après et expliquer le montage souhaité. Le monteur retrouve ensuite les demandes dans l'ordre des vidéos de la playlist.

## V1

- Projet lié à une playlist YouTube
- Vidéos conservées dans l'ordre de la playlist
- Lecteur YouTube intégré
- Timecode avec fenêtre ajustable avant/après
- Description libre du montage souhaité
- Vue monteur triée par vidéo puis par timecode
- États de traitement des demandes

## Évolutions envisagées

- Import des commentaires YouTube contenant des timecodes
- Détection et regroupement des moments drôles
- Export vers un format exploitable par un logiciel de montage
- Support d'autres sources vidéo

## Hors périmètre initial

Le projet ne génère pas automatiquement le montage final et ne remplace pas la décision éditoriale du monteur.

## Statut

Projet en phase de cadrage. Le dépôt est public pour documenter et développer le projet, mais aucune donnée privée de playlist ni aucun secret ne doit y être ajouté.

## Nom

Le nom fait référence au groupe **Ping Isen** et à l'idée d'un tunnel où les demandes passent des spectateurs vers le monteur.
